### Security COnfiguration

- Make a class
- Make a bean to manage it by Spring



Both are used to create spring managed object

@Component: used to anoate whole class
@Bean: used to anontate certain part of Class

Sometimes you cannot or don't want to annotate the class.
Instead, you define it manually inside a configuration class.

### Example:

@Configuration
public class AppConfig {

    @Bean
    public EmailService emailService() {
        return new EmailService();
    }
}


| `@Component`                                    |
| ----------------------------------------------  |
| Annotation on a class                           |
| Automatic detection through component scanning  |
| Best for your own classes                       |
| Less control over creation                      |
| Creates a Spring bean                           |


| Bean (`@Bean`)                                        |
| ----------------------------------------------------- |
| Annotation on a method                                |
| Explicit registration                                 |
| Best for third-party classes or custom initialization |
| Full control over object creation                     |
| Creates a Spring bean                                 |
