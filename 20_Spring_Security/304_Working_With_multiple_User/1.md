### HAving Multiple USer


using Database


UserDetailsService is one of the most important interfaces in Spring Security.
Tell Spring Security how to load a user from your data source (database, LDAP, etc.).


loadUserByUsername() is used to fetch the user from the database, convert it into a UserDetails object (which contains the username, encoded password, roles/authorities, and account status), and return it to Spring Security. The AuthenticationProvider then uses that UserDetails to verify the password and authenticate the user."

loadUserByUsername(String username)
Spring calls this automatically during authentication.


### What is UserDetails?

Spring Security doesn't work directly with your User entity.

Instead it expects a UserDetails object.

It contains information like:

Username
Password
Authorities (roles)
Account expired?
Locked?
Enabled?
Credentials expired?


During authentication

Imagine:

Username: sudhanva
Password: password123

Spring does:

1. loadUserByUsername("sudhanva")

↓

2. Gets UserDetails

↓

Username = sudhanva
Password = BCrypt Hash

↓

3. PasswordEncoder.matches(
       rawPassword,
       storedHash
   )

↓

4. Success

Notice:

UserDetailsService does NOT verify the password.

It only loads the user.

The password comparison is done by the AuthenticationProvider using the configured PasswordEncoder.
