### Authentication Porvider

It knows how to verify a user's credentials and return an authenticated user if they are valid.

User
  │
  ▼
Username + Password
  │
  ▼
AuthenticationFilter
  │
  ▼
AuthenticationManager
  │
  ▼
AuthenticationProvider  ← Does the actual verification
  │
  ├── Check username
  ├── Check password
  ├── Load roles/authorities
  └── Return authenticated user



Imagine Spring Security only had an AuthenticationManager.

How would it know how to authenticate?

Username & Password?
JWT?
OAuth (Google)?
LDAP?
API Key?
OTP?

Each authentication method is different.

Instead of putting everything inside one giant class, Spring uses different AuthenticationProviders.

Each provider knows how to authenticate one specific type of authentication.
