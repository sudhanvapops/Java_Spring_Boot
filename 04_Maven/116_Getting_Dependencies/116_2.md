### GAV

Every Library Has 3 Things

1. G: Group ID

    - if you create a library you have to make sure 
    it is unique throught the world
    - sometimes they just reverse thier domain \

    google.com\
    com.google

2. A: aritifact ID - project Name
3. V: version

4. same for all the library i download

EG:
Add this in pom.xml

<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>9.6.0</version>
    <scope>compile</scope>
</dependency>
