### Accessing Request Object in Spring Boot Way


In Spring Boot, @RequestParam is used to get values from the URL query parameters or form data.

OR you can do without it also
But Param name and Varibale name in Parameter Should match 



Example URL:

http://localhost:8080/hello?name=Sudhanva

Here name=Sudhanva is a request parameter.



@GetMapping("/hello")
public String hello(@RequestParam String name) {
    return "Hello " + name;
}



### Multiple Parameters

@GetMapping("/add")
public int add(@RequestParam int a,
               @RequestParam int b) {

    return a + b;
}

### @PathVariable

Gets data from URL path:

/user/101
@PathVariable int id

Example:

@GetMapping("/user/{id}")
public String user(@PathVariable int id) {
    return "User id: " + id;
}
