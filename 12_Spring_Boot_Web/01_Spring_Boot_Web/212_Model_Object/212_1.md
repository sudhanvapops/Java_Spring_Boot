### Model Object


You used Session 
Same but u can use Model


In Spring Boot, a Model object is mainly used to 
send data from the Controller to the View (like JSP, Thymeleaf, HTML templates).


A Model object stores data in server memory (RAM), but only for one request-response cycle.
It is NOT like Session.


Shared across pages?
Model: No
Session: Yes


Purpose
Model: Send data to View
Session: Store user state



Spring internally stores model data in the request scope.

### Basic Idea

When a user requests a page:

Controller receives the request
Controller prepares data
Data is stored in Model
View reads that data and displays it


model.addAttribute("name", "Sudhanva");
stores data inside the Model.


Then the View can access it.
JSP Example
<h1>Welcome ${name}</h1>
<h2>College: ${college}</h2>
