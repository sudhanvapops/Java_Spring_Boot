### Prepared Statments use for CRUD

use
String query = "insert into student (id,name,marks) values (?,?,?)"
? -> variables 

conn.prepareStatement(query);

To add variables
in order 

setInt(parameterIndex,data) -> id
setString(parameterIndex,data) -> name
setInt(parameterIndex,data) -> marks

if sepcifed order in query (id,name,marks)
then index 
    1 -> id
    2 -> name
    3 -> marks
else not specifeid order takes place as in db table column number
    1 -> id
    2 -> marks
    3 -> name
