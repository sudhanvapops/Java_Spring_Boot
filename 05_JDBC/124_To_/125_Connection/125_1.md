### Connect

### to run 

add this once in pom.xml

<build>
        <plugins>
            <plugin>
                <groupId>org.codehaus.mojo</groupId>
                <artifactId>exec-maven-plugin</artifactId>
                <version>3.6.3</version>
                <configuration>
                    <mainClass>com.jdbcsql.Main</mainClass>
                </configuration>
            </plugin>
        </plugins>
</build>

CMD To Run: mvn compile exec:java

### OR 

mvn clean install
mvn exec:java - after setting above plugin
