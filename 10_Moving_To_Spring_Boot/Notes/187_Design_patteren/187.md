### Controller → Service → Repository


Think of it like this:

MVC = overall application architecture
Controller → Service → Repository = backend layering pattern inside the application


### MVC

MVC stands for:

Model
View
Controller

It describes how the application is organized.


User -> Controller -> Model -> View -> User



1. Controller

Handles requests from user.

Example:

/login
/products
/add-user


2. View

What the user sees.

Examples:

JSP
Thymeleaf
React frontend
HTML page


3. Model

Application data/business objects.




### Controller-Service-Repository Pattern

This is a backend layering style commonly used in Spring apps.


Controller -> Service -> Repository -> Database


1. Controller Layer
Receives HTTP request.

2. Service Layer
Contains business logic.

This layer is where you:

validate rules
calculate things
combine operations
handle transactions

3. Repository Layer (DAO)
Talks to database.



Think it as

MVC
 ├── View
 ├── Model
 └── Controller
        └── Service
              └── Repository
