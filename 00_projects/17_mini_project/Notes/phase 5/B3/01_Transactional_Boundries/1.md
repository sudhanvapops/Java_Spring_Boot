Spring's proxy/interceptor sees @Transactional and starts it before invoking the method.

What is Spring Proxy:
    A Spring proxy is a wrapper object generated by the framework 
    that acts as a middleman between a caller and a target bean

    Client  ──>  Spring Proxy (Intercepts call & applies behavior)  ──>  Target Bean (Executes business logic)

    So when i add @Transactional

    the proxy intercepts the incoming request:
        Before the method: It might open a database transaction or check a cache.
        During the method: It delegates the call to your actual bean logic.
        After the method: It commits/rolls back the transaction or stores the result in the cache.
