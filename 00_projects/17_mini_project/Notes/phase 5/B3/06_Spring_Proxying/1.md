### What does Proxy Actually Do


proxy as a Wrapper
all the boiler plate code of making a transaction
try catch
commitTransaction()
else rollback throw e

all that are autmotacilly injected through 
Spring AOP


so proxy is a object that have all the code that needs to be injected when u want a transaction


So when the spring detects that this bean needs
@Transaction it will intercept the method

conceptually


                 Spring container

                       ↓

                       ↓

                       ↓
              actual BookService


then my controller gets the proxy object
