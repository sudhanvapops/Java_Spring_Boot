The Persistence Context is essentially Hibernate's working area for entities 
that belong to the current persistence operation/transaction.

It keeps track of entity instances and their state.



### Managed Entity

A managed entity is an entity currently associated with the persistence context.

Dirty checking is Hibernate automatically detecting that a managed entity has changed and generating the required SQL UPDATE when the transaction is flushed/committed.
