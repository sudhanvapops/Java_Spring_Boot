### When

MultipleBagFetchException occurs when Hibernate tries to fetch multiple bag collections in the same query

MultipleBagFetchException is typically encountered when fetching multiple bag collections
which are commonly mapped using @OneToMany or @ManyToMany.


// Can throw MultipleBagFetchException:
// both collections are bags
@Query("""
    SELECT b FROM Book b
    JOIN FETCH b.copies
    JOIN FETCH b.reviews
""")
List<Book> findBooksWithBoth();

@OneToMany itself isn't the problem. 
Fetching multiple bag collections in a single Hibernate query is the problem.

it happens at Query generation process
