You can use 
?1 ?2 for parametrs or :var 
setParameter(1,8)
setParameter("ram",8)

| Parameter in Query | Type       | How to Set                     |
| ------------------ | ---------- | ------------------------------ |
| `?1`               | positional | `setParameter(1, value)`       |
| `?2`               | positional | `setParameter(2, value)`       |
| `:model`           | named      | `setParameter("model", value)` |


Select will return string 
Multiple selct will return Object

| HQL Query                         | Result Type     |
| --------------------------------- | --------------- |
| `from Laptop`                     | `Laptop.class`  |
| `select brand from Laptop`        | `String.class`  |
| `select ram from Laptop`          | `Integer.class` |
| `select brand, model from Laptop` | `Object[]`      |

### Pro Tip (Hibernate Interview / Viva Trick)
    Instead of Object[], you can directly map results using DTO projection.
