### Fetching Data using HQL


Fetching data instead of Primary Key
use HQL

To execute HQL use Query from hibernate

1. By Ram
in SQL: select * from laptop where ram=32
in HQL: from Laptop where ram=32

- here Laptop is Entity name not table name

Query<Laptop> query;
query = session.createQuery("from Laptop where ram = :ram", Laptop.class);
query.setParameter("ram", 8);
laptops = query.getResultList();
