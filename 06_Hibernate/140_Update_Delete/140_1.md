### Update 

- Hibernate updates objects automatically if they are in Persistent State.
- You usually DO NOT call update manually.

Fetch + Modify + Commit
MUST happen in SAME SESSION

### Method 1: Recommended Way (Fetch → Modify)

Step 1: Fetch object
Step 2: Modify object
Step 3: Commit transaction

Hibernate detects change automatically.
