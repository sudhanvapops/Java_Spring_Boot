### SQL Config

- to show what sql query is running in hibernate
- use in XML

<property name = "hibernate.show_sql">true</property>

<property name = "hibernate.format_sql">true</property>
- for formated SQL Query

- Also Specifiy dialect since other db chnages its synatax little 
<property name = "hibernate.dialect">org.orm.dialect.PostgreSQLDialect</property>
