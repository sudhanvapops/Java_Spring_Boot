### How to change Column and row name from deafult

- how we get table name 
Table name we get it from Entity Name
Entity name Get it from class name Default


@Entity represents the Java object identity inside Hibernate/JPA.
"This Java class is a database entity."
✅ Entity name = Alien
✅ Used in Hibernate / JPQL queries
Used when writing HQL / JPQL, NOT SQL
Hibernate thinks in terms of Entity, not tables.

@Table → Database Table Name


If you want another Enity name 
@Entity(name="alien_name")

If you want just Table name 
@Table(name="alien_name")

### Column Name
