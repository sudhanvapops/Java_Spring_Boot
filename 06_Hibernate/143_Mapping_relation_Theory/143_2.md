### Normalization

Normalization is a database design technique used to:
    Reduce data redundancy
    Avoid data anomalies (insert, update, delete problems)
    Improve data consistency

Yes — often we do this by:
    Creating separate tables
    Linking them using primary key / foreign key relationships

But normalization is not only about removing duplicates.
It’s about organizing data properly based on dependencies.

Normalization is NOT just “removing duplicates”.
It is structuring data so that:
    Each fact is stored in one place
    Dependencies are maintained properly
    Redundancy is minimized

### Data Redundancy
Data redundancy = storing the same data multiple times unnecessarily.
