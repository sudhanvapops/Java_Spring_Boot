### Hibernate Intro

### Why Not JDBC for Large Applications?

For small projects or CLI-based tools, JDBC works well.
But in large-scale applications, especially when using Spring Framework, JDBC becomes difficult to manage because:

    Too much boilerplate code
    Manual query writing
    Manual object mapping
    Increased chances of errors
    Reduced developer productivity

JDBC involves many repetitive steps such as:

    Creating connections
    Writing SQL queries
    Executing statements
    Handling ResultSets
    Mapping database data to Java objects
    Managing transactions manually

### What is Hibernate?

Hibernate is an ORM (Object Relational Mapping) framework.
It removes most of the tedious database-related work.

- It automatically maps:
Java Objects ↔ Database Tables

Hibernate handles:
    SQL generation
    Object mapping
    Connection management
    Transaction handling
    Caching
    Database portability

This improves:

Developer productivity
Code maintainability
Code quality
