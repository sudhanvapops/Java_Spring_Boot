### Engine

Docker Engine is the software that creates, runs, and manages Docker containers.

 ┌────────┴────────┐
 │                 │
 ▼                 ▼
Build Images   Run Containers



What Docker Engine does
🏗️ Builds images from a Dockerfile.
📦 Creates containers from those images.
▶️ Starts, stops, and deletes containers.
🌐 Manages networking between containers.
💾 Manages volumes (persistent storage).
📥 Pulls images from Docker Hub or other registries.


### Here's what happens:

docker run nginx

Docker CLI sends the command.
Docker Engine checks if the nginx image exists.
If not, it downloads it.
It creates a container from the image.
It starts the container.
The Nginx server begins running.
