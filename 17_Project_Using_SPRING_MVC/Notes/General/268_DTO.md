### DTO

A DTO is an object used to transfer data between layers of your application without exposing your entity directly.


Without DTO
Controller returns the entity:

@GetMapping("/products/{id}")
public Product getProduct(@PathVariable Long id) {
    return productService.getProduct(id);
}

The client receives everything:
{
  "id": 1,
  "name": "Laptop",
  "description": "Gaming Laptop",
  "brand": "Dell",
  "price": 75000,
  "imageData": "very large byte array..."
}


### With DTO

Create a DTO:

@Data
@AllArgsConstructor
@NoArgsConstructor
public class ProductDTO {

    private Long id;
    private String name;
    private String brand;
    private BigDecimal price;
}

Controller:

@GetMapping("/products/{id}")
public ProductDTO getProduct(@PathVariable Long id) {
    Product product = productService.getProduct(id);

    return new ProductDTO(
        product.getId(),
        product.getName(),
        product.getBrand(),
        product.getPrice()
    );
}

Response:

{
  "id": 1,
  "name": "Laptop",
  "brand": "Dell",
  "price": 75000
}


### Why use DTOs?
Hide sensitive data
Passwords
Internal IDs
Large image data
Reduce response size
Don't send unnecessary fields.
Customize API responses
Different DTOs for different endpoints.
Prevent direct modification of entities
Keeps database models separate from API models.
